# Cynthia Montero — web premium

Sitio estático desarrollado en HTML, CSS y JavaScript vanilla.

## Archivos
- `index.html`: estructura semántica, metadatos SEO, Open Graph, Twitter Cards y datos estructurados.
- `styles.css`: dirección de arte, responsive mobile-first, accesibilidad y animaciones.
- `script.js`: navegación móvil, header inteligente, acordeón, animaciones por intersección y diálogos legales.
- `favicon.svg`, `site.webmanifest`, `robots.txt`, `sitemap.xml`.
- `assets/`: fotografías optimizadas en WebP.

## Publicación
Se puede servir directamente como sitio estático. La configuración SEO incluida usa como URL canónica:
`https://aitorhdezluna.github.io/cynthiamontero/`

Si se publica en otro dominio, sustituye esa URL en `index.html`, `robots.txt` y `sitemap.xml`.
